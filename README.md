# pddl-tsp

> **Course:** COSC 604 Artificial Intelligence · MSc, Khalifa University

### This PDDL or STRIPS solver can be used to solve problems in the navigation domain such as the Route-Finding Problem and the Travelling Salesperson Problem (TSP).

### To operate the file, you can run the following command line:
````
python search_engine.py -domain <domain.pddl> -problem <problem.pddl> -search [bfs|dfs|ids|ucs|bfgs|astar|all]
````
### To generate random TSP problems, you can use the ````randomly_generate(num_cities)```` function.
